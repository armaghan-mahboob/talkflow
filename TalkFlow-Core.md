# TalkFlow — Core

## Project Details

### Project Name

TalkFlow

### Project Type

Full-stack real-time chat application.

### Purpose

TalkFlow is a practice chat application built to learn and demonstrate full-stack application development.

### Main Functionality

- Real-time messaging

### Authentication

- Email-based authentication
- 4-digit OTP verification
- OTP delivered through email
- No password authentication
- Simple authentication architecture
- Logged-in user stored in localStorage

### Chat Scope

- 1-on-1 conversations are the current chat scope.
- Group chats are not part of the current scope.
